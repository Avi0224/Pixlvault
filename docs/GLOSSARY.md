# Photography 3D Platform

An open platform for photographers to upload their best work, featuring a curated 3D showcase and 2D galleries.

## Language

**Admin**:
The platform owner responsible for manually approving user uploads and curating which photos are featured in the Hall of Fame Sphere.

**Hall of Fame Sphere**:
The main interactive 3D globe displaying a curated selection of the top 50-100 photos, hand-picked by the Admin.
_Avoid_: 3D view, main page, homepage

**Explore Gallery**:
A 2D tab accessible from the main menu displaying all approved photos across the entire platform.
_Avoid_: Main menu, all work tab, feed

**Profile**:
A sleek, 2D masonry-grid page displaying all approved photos uploaded by a specific photographer.
_Avoid_: User page, account page

**Upload**:
The submission process for a new photo. Uploads are strictly compressed client-side to minimize hosting costs, and remain in a "Pending" state until the Admin manually approves them.
_Avoid_: Post, publish

**Visitor**:
An unauthenticated user who can view the Hall of Fame Sphere, explore the gallery, view profiles, and download photos.
_Avoid_: Guest, public user
